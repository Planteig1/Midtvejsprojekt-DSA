# Plane seat booking algorythm
## Install
Clone the repo, or fork it, and open the html file in your browser by double clicking the index.html file in your folder.
Already here should everything be up and running - if it is not, open index.html in your IDE of choice, and then open the index.html file in your browser.


## VSC Extensions
Only one extension was used, and it is for viewing the assignment pdf directly in VSC.

Name: vscode-pdf
VS Marketplace Link: https://marketplace.visualstudio.com/items?itemName=tomoki1207.pdf



## Running the simulation
When the visualisation is up and running, it will immediately load a rendition of the plane. To get the grid with visualisation, press the *"start simulation"* button below the plane. This will start the simulation, and the following visualisation.

You can also change some of the variables of the simulation, eg. changing amount of passengers, changing the starting seat price, changing the variance and so on.
